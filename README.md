# CL70

<br />

CL70은 제가 자작을 시도하며 처음 만들었던 키보드입니다.

아무것도 모르는 채로 시작하여 겪어야 했던 수 많은 시행 착오를 다른 분들은 최대한 줄였으면 하는 마음에 해당 키보드를 리메이크 하는 내용으로 [나만의 커스텀 커스텀 키보드 만들기 시리즈](https://www.notion.so/clein-kr/27f2e6fbea69806facf0daf639f351d5)를 노션에 연재해 두었으니 자작 키보드에 관심이 있으신 분들은 한 번 읽어 보시는 것을 추천 드립니다.
